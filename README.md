E-Commerce Platform (EJS, Node.js, Express, MongoDB)
This is a full-featured e-commerce platform built using Node.js, Express, MongoDB, and EJS for server-side rendering. The project follows an MVC architecture and provides APIs for seamless integration.

Features:
✅ User authentication & authorization (JWT-based)
✅ Product management (categories, attributes, pricing, images)
✅ Shopping cart & checkout process
✅ Order management (CRUD operations)
✅ Payment integration (Stripe/PayPal)
✅ Admin panel for store management
✅ Responsive UI with EJS templates

Tech Stack:
Backend: Node.js, Express.js, MongoDB, Mongoose
Frontend: EJS, Bootstrap, jQuery
Authentication: JWT, bcrypt
Payment: Stripe/PayPal integration
